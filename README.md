# 🌴 HH Goa 2026 — PFP Frame & Builder ID Card Generator

> Official shortlisting web application for **Hacker House Goa 2026**. Built with React, Vite, HTML5 Canvas, Tailwind CSS, and a Liquid Glass UI engine.

Live Web App: **[https://vedpatel2403.github.io/Hackerhousegoaid/](https://vedpatel2403.github.io/Hackerhousegoaid/)**

---

## 🌟 Key Features

- **Format A: PFP Frame / Overlay (1:1 Square)**: Generates 2000x2000px HD profile picture overlays with official HH Goa 2026 tropical cyber neon frames.
- **Format B: Builder ID Badge (4:5 Vertical)**: Generates 1200x1500px HD event badges with uploaded photo, builder name, stack pills, auto-generated title, ticket ID (`HH26-GOA-xxxx`), and scannable QR code.
- **Interactive Photo Controls**: Real-time zoom, rotation, pan X/Y, webcam selfie capture, and 6 photo filter styles (*Cyber Neon*, *Sunset Glow*, *Matrix*, *Monochrome*, *Vintage*).
- **Smart Title Randomizer**: Generate fun hacker titles with 1-click (*"Solana Gasless Alchemist"*, *"10x Vibe Coder"*, *"Prompt Whisperer"*, *"Zero-Knowledge Ninja"*).
- **Liquid Glass UI**: Apple Vision-inspired translucent glass panels, frosted backdrop blur, specular highlights, and morphing background ambient orbs.
- **1-Click X Share Intent**: Pre-filled tweet button with mandatory **`#FrameInGoa`** hashtag.

## 🚀 Local Development

1. Clone repository:
   ```bash
   git clone https://github.com/VedPatel2403/Hackerhousegoaid.git
   cd Hackerhousegoaid
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
